# QNX-Hackathon
Research, project ideas and roadmap for the QNX Global Hackathon.

## Selected concept: Faultline (working name)
A QNX-native failure-contract workbench that turns controlled service failures into reduced runnable reproducers and before/after evidence. Its reusable engine can serve native software and synthetic robotics/mobility workloads.

**Status:** research and planning, not implemented or submitted. QNX SDK licensing and cloud execution feasibility remain early validation gates.
