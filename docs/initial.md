## Research and planning assignment

1. Investigate the event deeply using primary sources.
2. Generate multiple strong project ideas, iterating through multiple passes rather than stopping at the first plausible concept.
3. Evaluate novelty, feasibility, demonstrable QNX use, judging fit and meaningful coverage of multiple prize categories.
4. Select one coherent project. Breadth should support a strong central demonstration, not unrelated features added solely to claim categories.
5. Complete **five distinct refinement passes** on the selected project and retain the research, alternatives, decisions and ideas under `docs/`.
6. Produce a build roadmap with milestones, dependencies, validation and submission deliverables.

Work is to take place entirely on the cloud computer, in parallel with separate open-source contribution work. This initial document records the brief; it is not a claim that a project has been built, tested, submitted or guaranteed to win.
