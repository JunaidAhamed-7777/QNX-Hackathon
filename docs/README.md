## Selected idea
Faultline turns a controlled QNX service failure into an explicit contract, reduced runnable reproducer and before/after evidence. Its reusable engine can apply to native services and synthetic robotics/mobility workloads. Enter primarily as Developer Tooling & Host Tools; broader applicability does not mean multiple category entries.

## Read this first
The contest allows one Overall prize plus one Bonus prize, not a sweep of all category prizes. Real QNX integration, license scope and cloud execution must be established before implementation claims. “Novel” and “competitive” are design objectives, not guaranteed outcomes.
